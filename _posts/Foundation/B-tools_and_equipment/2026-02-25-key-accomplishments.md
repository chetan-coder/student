## Sprint 2

In Jupyter notebooks, I was able to learn a lot with my team, and how to more effectively work with them with projects. This helped me later on with the game project for Night at The Musuem

Functions (P2): Functions are reusable blocks of code that do a specific job. They can take inputs (parameters) and return outputs.

Conditionals (P2): Conditionals like if, else if, and else help the program make decisions based on certain conditions.

Booleans (P2): Booleans are true or false values that are usually used in comparisons and decision-making.

Nested Conditionals (P2): This is when you put an if statement inside another if statement to create more detailed logic.

Iterations (P2): Iterations use loops like for or while to repeat code multiple times. (My team taught this lesson)

Arrays (P2): Arrays store multiple values in one variable and let you access them by index.

Strings (P2): Strings store text in JavaScript, and you can combine them, slice them, or change their format.

Mathematical Expressions (P2): These use operators like +, -, *, /, and % to perform calculations.

JSON and JavaScript Objects (P2): Objects store data in key-value pairs, and JSON is a format used to organize and transfer structured data.

Data Abstraction (P2): Data abstraction helps simplify complex data by organizing it with functions or objects to make code cleaner and easier to reuse.
